# Запуск копии бота

1. Распакуйте архив в новую папку.
2. Создайте нового бота через `@BotFather` и получите новый токен.
3. Скопируйте `.env.example` под именем `.env`.
4. Заполните в `.env` как минимум:
   - `BOT_TOKEN` — токен нового бота;
   - `ADMIN_IDS` — Telegram ID владельца;
   - `SERVICE_NAME` — название сервиса;
   - `SUPPORT_USERNAME` — контакт поддержки.
5. Для запуска на Windows откройте `setup_bot.cmd`, затем `start_bot.cmd`.
6. Для Railway создайте новый проект, добавьте переменные из `.env` и подключите Volume к `/data`.

Не используйте один `BOT_TOKEN` одновременно в двух запущенных копиях. Файл `.env` нельзя отправлять посторонним или публиковать в GitHub.

В архив не включены старая база пользователей, заявки, карты и секретные значения. API букмекерских платформ также не входит в шаблон и подключается отдельно по официальной документации каждой платформы.
